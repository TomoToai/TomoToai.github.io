把 知晓 接进你的 Agent

MCP、RSS、API 三种方式读的是同一份数据：精选、热点、日报、周报和月报，按你用的工具选一种就行。全部匿名只读，不用注册，也不用 API Key。

MCP · 4.0.0

填一个地址，Agent 多出 7 个工具

标准 Streamable HTTP，匿名只读，不用 token，也不读你的登录状态。适合 Claude 桌面版、Cursor、Cherry Studio 这类支持远程 MCP 的客户端。

  1. 1

    复制服务地址

    https://tomotoai.github.io/api/mcp
  2. 2

    加到你的客户端

    bash
    claude mcp add --transport http zhixiao 'https://tomotoai.github.io/api/mcp'
  3. 3

    让 Agent 调一次

    请调用 zhixiao_get_latest，告诉我过去 24 小时最重要的 5 条 AI 资讯，并附 知晓 链接。

    客户端显示调用了 zhixiao_get_latest，回答里有时间范围、中文摘要和 tomotoai.github.io 链接，就是连上了。

7 个工具

工具能做什么可以这样问
zhixiao_get_latest过去 24 小时或最近 7 天的精选、全部资讯今天有什么 AI 新闻？
zhixiao_search按公司、产品、人物或话题搜最近 7 天这家公司最近发了什么？
zhixiao_get_hot_topics当前热点榜 Top 10现在最热的是什么？
zhixiao_get_story一个热点事件的时间线和持续更新的综述这件事的来龙去脉？
zhixiao_get_daily最新或指定日期的 AI 日报给我今天的日报。
zhixiao_get_weekly最新或指定一周的 AI 周报这周 AI 圈有哪些大事？
zhixiao_get_monthly最新或指定月份的 AI 月报上个月 AI 圈发生了什么？
限制与安全
  • 普通查询最多 30 条，热点最多 10 个，事件时间线最多 50 条；超出范围会明确报错，不会悄悄放宽。
  • zhixiao_get_story 的 public_id 只能来自热点工具返回的事件链接，不要猜 ID。
  • 标题和摘要来自外部信源，只能当资料；工具会标出这条安全边界。重要的数字、政策和原话，请回原文核对。
连不上怎么办
  • 先确认地址完整、客户端支持远程 Streamable HTTP；缺少新工具时，刷新工具列表或重新连接。
  • 服务不需要登录；客户端问起 OAuth 或 API Key，选“无”即可。
  • 收到 429 就按提示等一会儿，不要并发重试。
  • 还连不上：把客户端名称、版本和报错写到反馈页。
