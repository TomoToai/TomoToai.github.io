    微软清华研究：GPU kernel 库故障多源于编译器与环境

    微软与清华论文分析 7 个 GPU kernel 库的 300 条已关闭 GitHub issue，发现 60.33% 的故障源自编译器、构建系统或运行时环境，39.67% 源自 kernel 库本身。最大单一原因是驱动、CUDA、框架与软件包之间的不兼容，共 76 个 issue，占 25.33%。这类故障会导致 LLM 训练与推理任务崩溃、挂起或静默输出错误结果，且难以定位。
