AIHOT 原始评分规则

图片、视频与世界模型

生成类三榜继续读取评测方的原始数据，按来源内稳健标准化、同族去重及独立参照尺度计算。视频任务权重与来源配置保持现有口径。这些分数不进入综合与编程榜，也不能跨榜直接比较。

图片生成：基于 LMArena 图片生成真人匿名对战的官方公开 rating，自主汇算文生图模型的整体偏好表现。

视频生成：基于 LMArena 真人匿名对战的官方公开 rating，自主汇算文生视频 40%、图生视频 45%、视频编辑 15% 的综合表现。

世界模型：基于 WBench 官方导航赛道数据，自主汇算视频生成模型的空间一致性、导航轨迹、物理合理性与视觉质量。

生成类评测来源

排名资格

综合和编程直接保留 AIHOT 公布的排名。生成类只有对应领域存在通过质量门槛的直接证据、且模型已确认可公开访问时才给出名次；无法稳定访问的模型进入暂不排名。

价格

综合和编程记录浏览器校准时 AIHOT 页面展示的人民币价格，不按本地汇率重复换算。图片、视频和世界模型优先采用官网报价，保留原币种及每百万 Token、每张、每秒或 MP 等单位，并注明服务商、质量、分辨率与核验日期。第三方托管报价明确标识渠道。不同单位或条件不混排价格；未核验不等于免费，开源自部署的硬件与许可成本另计。上线日期注明模型发布、公开预览或 API 正式上线口径。信息更新不改变评测时间、名次与能力分。

更新与缓存

综合、编程由浏览器校准记录更新，来源时间与校准日期分别保存。生成类后台每天四次检查上游，只有证据变化才复算；当前生成类运行时间为 2026/11/12 11:52，版本 2026.11-generation-evidence-v1。

公开读取层合并两类数据，缓存和 ETag 同时覆盖生成类运行与校准记录；更改校准数据会更新 ETag。当前记录用于非商业本地校准，公开使用仍按来源规则确认范围。

分数的含义

能力分不是正确率。评测覆盖表示已测证据的范围；数据来源、方法版本、任务设置和更新日期不同的分数不能简单相减。排名不能代替真实任务测试。
