评分怎么来的

知晓将不同评测的原始成绩转换到统一参照尺度：50 分是当前参照模型的平均水平，每 15 分约为一个标准差。分数用于同一方法版本内比较，不是正确率。

每个模型的单项成绩先按参照系折算、对齐到同一尺度，再按下面的权重合成综合分。评分不是正确率，也不代表它在你自己的任务上一定更好。

综合榜按五个领域加权，权重固定，不随当月模型多少变化。分类榜只取对应领域的成绩，不参与综合分。

进榜与暂不排名

一个模型要在某个榜上排名，需要同时满足两点：在这个领域至少有一个通过质量门槛的直接证据单元，并且已经能通过官方 API 或公开权重稳定调用。

已有成绩但不能稳定公开访问的模型会放进“暂不排名”，并标明尚未正式上线或暂无稳定公开访问方式。状态变化后，下一次计算会自动更新名次。

更新与缓存

知晓当前榜单由自主汇算模块直接发布：最新计算时间为 2026/11/11 14:52（北京时间）。 页面与公开接口缓存 5 分钟；只有官方评测证据发生变化才触发新一轮计算和原子替换。

评分口径版本为 2026.11-robust-evidence-v2。口径调整会换版本号，新旧版本的分数不直接比较。

知晓的更新规则

  • 每天检查四次第三方评测上游；不是每天把全部模型重新跑一遍。
  • 新成绩一经收录就参与重新计算；正式可用且在对应榜有直接证据的模型进入排名。
  • 网页刷新、价格变化或抓取时间不算重新评测，只有评测证据变化才影响能力分。
  • 来源暂时不可用时沿用最近有效成绩；单个模型消失最多沿用七天内核验过的同版本成绩。
  • 新结果在同一事务内完整写入；整轮失败时事务回滚，线上继续读取上一份完整结果。
  • 新评测对照模型覆盖不足 60%，或长期跟不上主要模型时暂停计分，补齐后恢复。

怎么读才不误判

  • 分数是评测成绩的折算，不是正确率，也不等于真实业务里的成功率。
  • 相差 3 分以内，先后顺序可能随下一次评测变化，不必当成胜负。
  • “评测覆盖”表示这个模型在该领域被测了多少项、覆盖了多少，覆盖低的模型分数更不稳定。
  • 分类榜只看该领域，排名高不代表综合能力强；综合榜也不能替代你按自己的任务做小样本测试。
  • 价格变动频繁，下单前请以服务商官网为准。
